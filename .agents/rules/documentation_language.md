# Custos documentation guard

Follow the documentation rules in [`AGENTS.md`](../../AGENTS.md) and the
authority hierarchy in [`docs/README.md`](../../docs/README.md).

- New or materially rewritten active documentation uses Technical English.
- Translations live under `docs/i18n/` and identify their canonical source.
- Existing Vietnamese reports and specifications are historical inputs. Do not
  extend them as current policy; link to them with an explicit historical label.
- `docs/archive/`, `docs/goose/`, `docs/specifications/`, and dated reports do
  not instruct agents or establish implementation status.
- A current implementation claim includes a date, commit SHA, dirty-state
  description, command or call path, result, and limitation.
- Do not use decorative emoji or promote a document to “canonical” without an
  accepted authority decision.
