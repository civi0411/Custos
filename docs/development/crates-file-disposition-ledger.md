## Giới hạn và nghiệm thu

Inventory này bao phủ danh sách file của snapshot, không bao phủ ignored build output hoặc mọi feature có thể phát sinh trên OS khác. Đọc báo cáo chính để biết findings cụ thể và kết quả kiểm tra. Không dùng table như script tự động rename/xóa. Trước implementation, regenerate inventory nếu HEAD/file hash đã thay đổi và xem lại mọi path có caller mới.
